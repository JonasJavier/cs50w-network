# Deploying to Netlify + Render + Neon

> **Reference deployment:** https://network-jonasjavier.netlify.app (web) · https://network-api-fg8c.onrender.com (API) · Postgres and media on Neon.

All three providers have a free tier that is enough for the demo:

| Piece | Provider | Config in the repo |
| --- | --- | --- |
| React SPA (`frontend/`) | Netlify | [`netlify.toml`](../netlify.toml) |
| Django API (`backend/`) | Render (Docker, free web service) | [`render.yaml`](../render.yaml) |
| PostgreSQL | Neon | — |
| Uploaded media | Neon Object Storage (S3-compatible, public bucket) | — |

Free-plan trade-off: the Render service sleeps after 15 minutes without traffic, so the first request after a pause takes about 50 seconds. Its disk is ephemeral, which is why uploads go to object storage instead of `MEDIA_ROOT`.

## 1. Neon

1. Create a project (region **AWS US East 2 (Ohio)**, which supports Object Storage) with **Postgres** and **Object storage** enabled.
2. Add a bucket named `media` with visibility **Public**.
3. Copy the Postgres connection string (*Connect → Postgres database*). It already ends with `?sslmode=require`.
4. In *Connect → Storage → .env* note `AWS_ENDPOINT_URL_S3`, then create a credential with `storage:read` and `storage:write` (*Settings → Credentials*). The secret is shown only once.

## 2. Render (API)

*New → Blueprint*, pick this repository, and Render reads `render.yaml`. Fill in the values it asks for:

| Variable | Value |
| --- | --- |
| `DATABASE_URL` | Neon connection string |
| `CORS_ALLOWED_ORIGINS` | the Netlify origin, e.g. `https://network-jonasjavier.netlify.app` |
| `AWS_S3_ENDPOINT_URL` | Neon `AWS_ENDPOINT_URL_S3` |
| `AWS_ACCESS_KEY_ID` / `AWS_SECRET_ACCESS_KEY` | Neon storage credential |

`DJANGO_SECRET_KEY` is generated by Render. `ALLOWED_HOSTS` and `CSRF_TRUSTED_ORIGINS` pick up `RENDER_EXTERNAL_HOSTNAME` automatically. Migrations run on every boot, and `SEED_ON_START=1` loads the demo data idempotently.

## 3. Netlify (web)

Import the repository. `netlify.toml` sets the base directory (`frontend`), the build command and the SPA fallback. Add one environment variable, then redeploy:

| Variable | Value |
| --- | --- |
| `VITE_API_URL` | the Render URL, e.g. `https://network-api-fg8c.onrender.com` (no trailing slash) |

`VITE_SHOW_DEMO_ACCOUNTS=0` hides the demo-account helper on the login page.

## Custom domain

Add the domain in Netlify (*Domain management*), then add its origin to `CORS_ALLOWED_ORIGINS` on Render. For an API subdomain, add it as a custom domain on Render and list it in `DJANGO_ALLOWED_HOSTS`.
